# Tutorials — Mobile Nutrition App

> Learning-oriented guides that teach by doing

## Purpose
Tutorials help newcomers accomplish a complete goal end-to-end with minimal context switching. They are linear and prescriptive.

## Writing Guidelines
- Show steps, not options
- Keep scope small (30–60 minutes)
- Provide copy-paste commands and screenshots where relevant
- Link to reference docs for background

## Tutorial Index (planned)
- Getting the dev environment ready (iOS/Android/Web)
- First sign-in via Cognito Hosted UI (mobile + web)
- Implementing secure token storage (Keychain/Keystore)
- Adding a logout button with full session cleanup
- Observability 101: adding request IDs and reading logs
